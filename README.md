# 🔐 Passwort-Generator

Ein sicherer Passwort-Generator in C#, mein erstes eigenes Projekt während meiner Weiterbildung zum C#-Software-Entwickler.

## Funktionen
- Wählbare Passwortlänge
- Optionen für Großbuchstaben, Zahlen und Sonderzeichen
- Kryptografisch sicherer Zufall (`RandomNumberGenerator`)
- Stärke-Check (Schwach / Mittel / Stark)

## Starten
1. Projekt in Visual Studio 2022 öffnen
2. Mit F5 starten

## Was ich dabei gelernt habe
- Ein und Ausgabe in der Konsole
- Variablen, Schleifen und Bedingungen
- Eigene Methoden schreiben
- Sicheren Zufall für Passwörter nutzen
